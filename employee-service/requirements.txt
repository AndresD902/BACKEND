# ── NOTAS DE INSTALACIÓN ────────────────────────────────────
# 1. Requiere Node.js >= 18
# 2. Requiere PostgreSQL >= 14 corriendo y accesible
# 3. Requiere auth-service corriendo en el puerto 3001 (verificación JWT)
# 4. Requiere history-service corriendo en el puerto 3006 (registro de cambios)
# 5. Configurar .env antes de ejecutar (ver .env.example)
# 6. Ejecutar migraciones antes del primer inicio:
#       npm run migrate
# 7. Para desarrollo:
#       npm run dev
# 8. Para producción:
#       npm run build && npm start


# ── SCRIPTS NPM ─────────────────────────────────────────────
# npm run dev              → Servidor con hot-reload (ts-node-dev)
# npm run build            → Compilar TypeScript a dist/
# npm start                → Iniciar servidor compilado
# npm test                 → Ejecutar tests con Jest
# npm run test:coverage    → Tests + reporte de cobertura (umbral: 90%)
# npm run migrate          → Aplicar migraciones pendientes
# npm run migrate:down     → Revertir última migración
# npm run lint             → Verificar código con ESLint
# npm run format           → Formatear código con Prettier


# ── VARIABLES DE ENTORNO REQUERIDAS ─────────────────────────
# DATABASE_URL             → postgresql://user:pass@host:5432/employee_db
# JWT_SECRET               → Mismo secreto compartido con auth-service
# PORT                     → Puerto del servidor (default: 3002)
# HISTORY_SERVICE_URL      → URL base de history-service (default: http://localhost:3006)
# AUTH_SERVICE_URL         → URL base de auth-service (default: http://localhost:3001/api/v1)
# INTERNAL_API_KEY         → Clave compartida para endpoints internos entre servicios
# AWS_REGION               → Región AWS (ej: us-east-1)
# AWS_ACCESS_KEY_ID        → Credenciales AWS
# AWS_SECRET_ACCESS_KEY    → Credenciales AWS
# AWS_S3_BUCKET_NAME       → Nombre del bucket S3 para documentos
