# ── NOTAS DE INSTALACIÓN ────────────────────────────────────
# 1. Requiere Node.js >= 18
# 2. Requiere PostgreSQL >= 14 corriendo y accesible
# 3. Configurar .env antes de ejecutar (ver .env.example)
# 4. Ejecutar migraciones antes del primer inicio:
#       npm run migrate
# 5. Para habilitar envío real de correos, configurar SMTP_USER y SMTP_PASS en .env
#    Si no están configuradas, los correos se imprimen en consola (modo desarrollo).
# 6. Para desarrollo:
#       npm run dev
# 7. Para producción:
#       npm run build && npm start


# ── SCRIPTS NPM ─────────────────────────────────────────────
# npm run dev              → Servidor con hot-reload (ts-node-dev)
# npm run build            → Compilar TypeScript a dist/
# npm start                → Iniciar servidor compilado
# npm test                 → Ejecutar tests con Jest (--runInBand)
# npm run test:watch       → Tests en modo watch
# npm run test:coverage    → Tests + reporte de cobertura (umbral: 60%)
# npm run migrate          → Aplicar migraciones pendientes
# npm run migrate:down     → Revertir última migración
# npm run lint             → Verificar código con ESLint
# npm run format           → Formatear código con Prettier


# ── VARIABLES DE ENTORNO REQUERIDAS ─────────────────────────
# NODE_ENV                     → development | production | test
# PORT                         → Puerto del servidor (default: 3001)
# SERVICE_NAME                 → auth-service
# JWT_SECRET                   → Secreto para firmar JWT (mín. 32 caracteres)
# JWT_EXPIRES_IN               → Duración del access token (1h)
# BCRYPT_SALT_ROUNDS           → Rondas de bcrypt (recomendado: 12)
# DATABASE_URL                 → postgresql://user:pass@host:5432/auth_db
# REFRESH_TOKEN_EXPIRES_DAYS   → Días de validez del refresh token (default: 7)
# RESET_TOKEN_EXPIRES_MINUTES  → Minutos de validez del token de reset (default: 15)
# FRONTEND_URL                 → URL del frontend (default: http://localhost:5173)
# SMTP_HOST                    → Host SMTP (default: smtp.gmail.com)
# SMTP_PORT                    → Puerto SMTP (default: 587)
# SMTP_USER                    → Cuenta de correo (si vacío → modo consola)
# SMTP_PASS                    → App Password de Gmail
# SMTP_FROM                    → Dirección "From" (default: SMTP_USER)
