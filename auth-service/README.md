# Auth Service

Authentication and authorization microservice for the Employees Administration System.

## Overview

This service is responsible for identity and access management within the platform.  
It provides the base infrastructure for authentication, authorization, and role-based access control.

The service is part of a microservices-based architecture built with TypeScript.

## Main Responsibilities

- User authentication
- User authorization
- Role-based access control
- Password protection
- Secure API access
- Base user and role management endpoints
- Health check endpoint

## Tech Stack

- Node.js
- Express.js
- TypeScript
- Jest
- ESLint
- Prettier
- Docker
